1. Executive Summary & Project Vision

1.1 The Problem Space

In the modern technical recruitment landscape, both students and recruiters face severe systemic disconnects: - Students lack actionable clarity regarding the exact skills demanded by industry roles. Traditional job descriptions are verbose, vague, and uncalibrated, leaving candidates unsure whether their academic preparation qualifies them for entry-level or junior engineering positions. - Recruitment Platforms rely on black-box keyword matching algorithms that penalize qualified candidates due to arbitrary keyword phrasing or provide candidates with zero transparent feedback when an application is rejected. - Skill Acquisition is fragmented. Students study disparate courses without an integrated roadmap that connects self-study directly to verified job openings and interactive mock interview evaluation.

1.2 The Skill Link Solution

Skill Link is an enterprise-grade, full-stack career intelligence, educational guidance, and transparent recruitment platform designed to eliminate the ambiguity between student capability and industry demand.

1.3 Key Innovations

  1. Explainable Deterministic Matching: Unlike opaque scoring models, Skill Link utilizes a deterministic matching engine that breaks down candidate-job alignment into 70% Required Skills, 30% Preferred Skills, and a +5% Project Evidence Bonus.
  2. Local Intelligent AI Architecture: The platform operates with 100% offline intelligence out-of-the-box (zero mandatory external API dependencies) via deterministic mathematical algorithms, heuristic NLP, and curated question rubrics, while maintaining plug-and-play compatibility with Gemini, OpenAI, and Anthropic.
  3. Immersive 3D WebGL Storytelling: A custom Three.js continuous spline journey canvas seamlessly guides first-time visitors from initial skill exploration down to career triumph with smooth scroll-coupled camera interpolation.
  4. Cinematic Dark Glassmorphism UI: High-contrast, accessibility-tested visual tokens (#05070D background, frosted glass panels with 24px backdrop blur, vibrant lavender/cyan accents) deliver an exceptionally modern desktop experience.

2.2 Tier Decomposition & Data Flow

Client Tier

Built with modern web technologies: - React 19.2.8 featuring concurrent rendering primitives. - TypeScript 5.8 guaranteeing compile-time type safety across all domain entities. - Vite 8.3 delivering instant hot module replacement (HMR) and sub-second builds. - Three.js 0.174 managing the background 3D canvas with custom geometries, ambient particle fields, and mathematical spline curves.

API Gateway & Communication Protocol

  • Frontend and backend communicate via asynchronous RESTful JSON APIs prefixed with /api/v1.
  • In development, Vite's internal proxy maps browser requests from http://localhost:5173/api directly to http://127.0.0.1:8000, resolving cross-origin credential issues and Windows IPv6/IPv4 address resolution mismatches.
  • All secure endpoints require the Authorization: Bearer <JWT> header.

Application Tier

Powered by Python 3.13 and FastAPI: - Asynchronous route handlers (async def and synchronous def where database I/O is offloaded to worker threads). - Pydantic v2 validation models with ConfigDict(from_attributes=True) validating inbound JSON bodies and outbound serialization. - Strict Role-Based Access Control (UserRole.STUDENT, UserRole.RECRUITER, UserRole.ADMIN).

Persistence Tier

  • SQLAlchemy 2.0 ORM employing modern declarative base syntax (Mapped[T] and mapped_column()).
  • Session management through a scoped generator get_db() with automatic commit/rollback and connection pooling.

2.3 Dual-Database Architecture (SQLite & PostgreSQL)

To enable frictionless academic evaluation and seamless enterprise deployment: 1. Local Zero-Setup Mode (Default): Utilizes SQLite (sqlite:///./careerbridge.db). Alembic migrations operate with render_as_batch=True to support SQLite schema alterations without dropping tables. 2. Production Mode: Switching requires only setting DATABASE_URL=postgresql+psycopg2://user:pass@host:5432/careerbridge in .env. The ORM models and Alembic migration scripts are 100% dialect-agnostic.

3. Algorithmic & AI Engine Architecture

3.1 Deterministic Skill Gap & Career Intelligence Engine

Located in backend/app/services/career_intelligence.py.

Core Mathematical Formula

The alignment score between a student profile and a target career role is computed deterministically:

$$\text{Alignment Score} = \left( \frac{\sum_{i=1}^{N} \min(S_i, R_i) \cdot W_i \cdot V_i}{\sum_{i=1}^{N} R_i \cdot W_i} \right) \times 100$$

Where: - $S_i \in [1, 5]$: Student's demonstrated proficiency in skill $i$ (defaults to $0$ if unacquired). - $R_i \in [1, 5]$: Required proficiency level specified for the target role. - $W_i \in [0.8, 1.5]$: Importance weight of skill $i$ (Critical skills = $1.2 - 1.5$, Recommended = $0.8 - 1.0$). - $V_i$: Verification factor: - $V_i = 1.00$ for verified skills (demonstrated via linked GitHub project or completed platform assessment). - $V_i = 0.85$ for unverified self-reported skills. - $V_i = 0.70$ for unassessed baseline competencies.

6-Axis Radar Metric Distribution

The engine projects the student's competencies onto six standard industry dimensions: 1. Algorithms & Computational Foundations 2. Systems Architecture & Low-Level Design 3. Machine Learning & Statistical Modeling 4. Data Engineering & Relational Pipelines 5. Software Engineering & Component Architecture 6. DevOps, Cloud & Production Infrastructure

Each axis computes the ratio of student capability against role expectations, returning current, required, and cohort_average values for the interactive radar visualization.

Skill Gap Classification

  • Optimal / Proficient ($\text{Gap} \le 10\%$): Marked as verified student strength.
  • Moderate / Needs Improvement ($10\% < \text{Gap} \le 30\%$): Targeted for milestone practice.
  • Critical Gap ($\text{Gap} > 30\%$): Prioritized at the top of the student's dynamic learning roadmap.

3.2 Transparent Job Matching Engine (70/30 Rule + Project Bonus)

Located in backend/app/services/matching_engine.py.

Unlike opaque black-box recruiters, Skill Link implements a mathematically transparent matching model:

┌─────────────────────────────────────────────────────────────────┐
│                    TRANSPARENT MATCH FORMULA                    │
├────────────────────────────────┬────────────────────────────────┤
│ Component                      │ Maximum Weight                 │
├────────────────────────────────┼────────────────────────────────┤
│ Required Skills Match          │ 70.0%                          │
│ Preferred Skills Match         │ 30.0%                          │
│ Project Evidence Bonus         │ +5.0%                          │
├────────────────────────────────┼────────────────────────────────┤
│ TOTAL MAXIMUM MATCH SCORE      │ 100.0% (Clamped)               │
└────────────────────────────────┴────────────────────────────────┘

Algorithmic Procedure

  1. String Normalization: Skill names are normalized (lowercased, hyphens and slashes replaced with spaces) to ensure resilient matching across naming conventions (e.g., react.js matches React, ci/cd matches CI-CD).
  2. Competency Ingestion: The engine compiles all student skills and scans student_projects for demonstrated technologies and tools.
  3. Required Skills Ratio: $$\text{Req Score} = \left( \frac{\text{Matched Required Skills}}{\max(1, \text{Total Required Skills})} \right) \times 70.0$$
  4. Preferred Skills Ratio: $$\text{Pref Score} = \left( \frac{\text{Matched Preferred Skills}}{\max(1, \text{Total Preferred Skills})} \right) \times 30.0$$
  5. Project Evidence Bonus: If the student has at least one repository or live project link matching any required skill, an additional $+5.0\%$ is added.
  6. Explainable Breakdown: The engine returns explicit lists of matched_skills, missing_critical_skills, and recommended_to_learn directly to the client interface.

3.3 ATS Resume NLP Diagnostic Engine

Located in backend/app/services/resume_service.py.

Pipeline Architecture

  1. Safe Byte Ingestion: Accepts PDF or TXT uploads. PyPDF iterates through document pages, extracting plaintext while handling corrupted byte buffers via fallback UTF-8 decoding.
  2. Lexical Skill Extraction: Matches document text against the platform's relational skill catalogue using regular expression word boundaries (\b<skill>\b).
  3. Target Role Comparative Diagnostics: Compares identified skills against the requested target role's critical requirements, calculating a Resume Readiness Score (0–100): - Found Skills Ratio: up to 50 points - Absence of Missing Critical Requirements: up to 30 points - Structural Quality & Impact Action Verbs: up to 20 points
  4. Action-Verb Enhancement Suggestions: Scans candidate bullet points for weak verbs (e.g., "helped with", "worked on", "handled") and suggests high-impact alternatives (e.g., "Architected", "Spearheaded", "Optimized", "Quantified").

3.4 Rubric-Grounded AI Mock Interview Simulator

Located in backend/app/services/interview_service.py.

Question Bank & Rubric Design

The simulator provides structured questions across four technical specializations: 1. AI / Machine Learning Engineer (Self-attention vs cross-attention, gradient explosion, loss divergence diagnostics). 2. Full-Stack Systems Engineer (ACID transactions vs eventual consistency, race condition prevention, React 19 server components). 3. Data Scientist & Quantitative Analyst (A/B test sample size formulas, feature collinearity, ROC-AUC calibration). 4. Cloud & Distributed Systems Architect (CAP theorem trade-offs, Raft consensus elections, container security isolation).

4-Dimensional Evaluation Rubric

Student responses are graded across four standardized criteria: 1. Technical Accuracy (0–100): Correctness of core architectural assertions and terminology. 2. Reasoning & Depth (0–100): Ability to substantiate claims with first-principles reasoning. 3. Practical Trade-offs (0–100): Awareness of computational cost, latency, scalability, and maintainability. 4. Clarity & Communication (0–100): Conciseness, structure, and professional delivery.

The overall session score is recorded in interview_sessions alongside detailed feedback and model benchmark answers.

3.5 Contextual Career Assistant Engine (Zero-Hallucination)

Located in backend/app/services/assistant_service.py.

Grounded Knowledge Base

To prevent AI hallucinations, the assistant is deeply integrated with the platform's active database: - Reads the logged-in student's target role, verified skills, and roadmap progress. - Queries active job listings posted by verified employers. - When answering career queries, references real open positions, actual required competencies, and specific platform learning resources. - If an external LLM (Gemini, OpenAI, Anthropic) is configured via backend/.env, prompts are injected with grounded JSON context. If the provider times out or fails, the engine falls back to local intelligent generation seamlessly.

  • Result: tsc -b && vite build succeeds with 0 errors in <500ms, generating an optimized production bundle.

10.3 Security Auditing & Privacy Boundaries

  • Password Hashing: Bcrypt with auto-generated salt; plain text passwords are never logged or stored.
  • Token Security: HS256 signed JWT tokens containing user ID subject claims.
  • Privacy Guards: Student email and phone numbers are hidden from recruiter discovery searches until an application is officially moved to SHORTLISTED or INTERVIEW stage.
  • SQL Injection Prevention: SQLAlchemy parameterized queries eliminate SQL injection vulnerabilities.
  • XSS Mitigation: React JSX automatic string escaping prevents cross-site scripting attacks.

10.4 Local & Production Deployment Setup

One-Click Local Launch (Windows)

  1. Run start_backend.bat in one terminal window (starts Uvicorn on port 8000).
  2. Run start_frontend.bat in a second terminal window (starts Vite on port 5173).
  3. Access the application at http://localhost:5173.

Production Deployment Checklist

  1. Configure a production PostgreSQL database instance.
  2. Set environment variables: env DATABASE_URL=postgresql+psycopg2://user:password@host:5432/careerbridge JWT_SECRET_KEY=generate_a_cryptographically_secure_random_string_64_chars ENVIRONMENT=production
  3. Run database migrations: alembic upgrade head
  4. Seed initial catalogue: python -m app.db.seed
  5. Build the React frontend: npm run build in landing page/ and serve static assets via Nginx or Cloudflare Pages.
  6. Run Uvicorn behind a production reverse proxy with Gunicorn worker processes: bash uvicorn app.main:app --host 0.0.0.0 --port 8000 --workers 4
